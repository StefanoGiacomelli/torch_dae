# Contributing

Read the repository's
[CONTRIBUTING.md](https://github.com/StefanoGiacomelli/torch_dae/blob/main/CONTRIBUTING.md) before
making changes. Contributions must preserve evidence provenance, checkpoint-specific identity,
isolated model runtimes, and the public waveform contract.

Public APIs require NumPy-style docstrings and explicit inclusion in the curated API pages. Run the
checks in {doc}`testing` and build this documentation as described in {doc}`documentation`.
